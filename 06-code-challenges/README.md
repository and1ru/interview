# 06 - Code Challenges

A collection of classic interview challenges. Each file includes the problem statement, a solution explained with comments, and examples using `console.log`.

## How to use them

1. Read the problem statement at the top of the file.
2. **Try to solve it yourself first**, covering up the solution.
3. Run the file with Node.js to see the results:
   ```bash
   node 06-code-challenges/reverse-string.js
   ```
4. Compare your solution with the one in the file.

## Included challenges

| File | Challenge |
|---|---|
| `reverse-string.js` | Reverse a string |
| `palindrome.js` | Detect whether a text is a palindrome |
| `remove-duplicates.js` | Remove duplicates from an array |
| `count-characters.js` | Count character frequency |
| `max-number.js` | Find the largest number |
| `flatten-array.js` | Flatten a nested array |
| `fizzbuzz.js` | The classic FizzBuzz |

## Tip

In an interview, there is almost always more than one way to solve a challenge. First arrive at a solution that works (even a simple one), explain it, and then talk about how to improve it. A correct and clear solution is worth more than a "clever" one that you can't explain.
