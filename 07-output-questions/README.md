# 07 - Output questions

"What does this code print?" is one of the most common questions in JavaScript interviews. It tests whether you truly understand how the language works.

## How to use them

1. Open an `output-XXX.js` file.
2. Read the code and **predict the output without running it**. Write it down on paper.
3. Run the file to check:
   ```bash
   node 07-output-questions/output-001.js
   ```
   Or with the npm script:
   ```bash
   npm run output:001
   ```
4. Review the explanation in [`answers.md`](answers.md).

## Files

| File | Concepts it tests |
|---|---|
| `output-001.js` | `typeof null`, `==` vs `===`, coercion |
| `output-002.js` | `var` in `setTimeout`, closures |
| `output-003.js` | hoisting, TDZ |
| `output-004.js` | Promises vs setTimeout, event loop |
| `output-005.js` | arrays and references, objects and mutability |

## Important

Don't cheat by running the code before predicting. The value of this exercise lies in **trying to guess first**: that's where you discover which concepts you don't fully understand.
